# Netflix-Clone-Project
# StreamView - Media Content Dashboard

Netfilx clone Project frontend project built with **React + Vite** and the **TMDB API**.

## 🚀 Live Demo
Experience the live deployment here: **[deployed page](https://netflix-clone-project-1-jytrhoxhm-yabets123d-ux.vercel.app/)**

## ✨ Core Features
* **Dynamic Content Rows:** Smoothly animated, horizontal scroll-carousels displaying categorized media banners.
* **Responsive Client Interface:** Fluid layout configurations adapting to mobile, tablet, and desktop screens.
* **Component Optimization:** Built with React functional components to ensure fast load speeds and minimal re-renders.
* **Vite-Engineered Pipelines:** High-speed development and bundling system powered by Vite.
* **Configurable Environments:** Centralized environment variable structure for external endpoints.

## 🛠️ Tech Stack & Linting
* **Core Framework:** React 19+
* **Build System:** Vite
* **Linting & Code Quality:** Oxlint (High-speed JavaScript/TypeScript linter)
* **Hosting Platform:** Vercel Global Edge Network

## 📦 Installation & Local Configuration

Follow these steps to configure and run the repository locally on your computer:

### 1. Clone the project files
```bash
git clone (https://github.com/yabets123d-ux/Netflix-Clone-Project.git)
cd Netflix-Clone-Project
```

### 2. Configure Environment Secrets
This project requires specific environment variables to function properly. Copy the template provided in the root directory:
```bash
cp .env.example .env
```
*Open the newly created `.env` file and replace the placeholder values with your valid API endpoint configuration details.*

### 3. Initialize dependencies
```bash
npm install
```

### 4. Boot up the development engine
```bash
npm run dev
```
Once initialized, open your browser and head over to `http://localhost:5173` to explore the project.
